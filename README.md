# homebrew-meetily-memory

Homebrew tap for `meetily-memory`.

```sh
brew tap 0x12th/meetily-memory
brew install meetily-memory
```

This repository is published as `github.com/0x12th/homebrew-meetily-memory`.

The formula contains placeholder SHA-256 values until the first release exists.
Update it from the main `meetily-memory` repository after each GitHub Release:

```sh
scripts/update-homebrew-formula.sh 0.1.0 ../homebrew-meetily-memory
```
